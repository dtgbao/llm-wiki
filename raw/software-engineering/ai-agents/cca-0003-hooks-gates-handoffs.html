Hook 1: prerequisite gate (PreToolUse)

A PreToolUse hook runs before a tool executes. It can allow, deny or modify the call (Agent SDK: hooks).

verified = {"customer_id": None}
GATED = {"mcp__support__lookup_order", "mcp__support__process_refund"}

async def record_verified(inp, tool_use_id, ctx):          # PostToolUse on get_customer
    if inp["tool_response"].get("verified"):
        verified["customer_id"] = inp["tool_response"]["customer_id"]
    return {}

async def gate(inp, tool_use_id, ctx):                      # PreToolUse
    if inp["tool_name"] in GATED and not verified["customer_id"]:
        return {"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "permissionDecision": "deny",                     # the call never runs
            "permissionDecisionReason": "Verify identity with get_customer first."}}
    return {}                                                 # empty = allow

permissionDecisionReason tells the model why the call failed. The model then calls get_customer and tries again. Allowed values are allow, deny, ask and defer. You can also return updatedInput to rewrite the arguments (SDK docs).

Hook 2: policy interception and redirect

async def refund_limit(inp, tool_use_id, ctx):              # PreToolUse, matcher: process_refund
    if inp["tool_input"]["amount"] > 500:
        return {"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "permissionDecision": "deny",
            "permissionDecisionReason":
              "Refunds over $500 need a human. Call escalate_to_human with a handoff summary."}}
    return {}

The deny blocks the violation. The reason redirects the agent to the alternative workflow: human escalation.

Hook 3: normalize data (PostToolUse)

A PostToolUse hook runs after the tool returns and before Claude sees the result. Set updatedToolOutput to replace the output. Set additionalContext to append to it (SDK docs).

Raw output from three MCP tools          After the PostToolUse hook
order_svc:   {"placed": 1730851200}         {"placed": "2024-11-06"}
billing_svc: {"date": "2024-11-06T00:00Z"}  {"date":   "2024-11-06"}
ship_svc:    {"status": 3}                  {"status": "shipped"}

One format reaches the model. The model does not convert anything, so it makes no conversion errors.

Structured handoff

The human agent does not have the conversation transcript. So the escalation must carry everything they need to act.

{"customer_id": "C-77",            "issue": "Refund request, order #8812, damaged",
 "root_cause": "Carrier damage; photo confirms",
 "attempted": ["verified identity", "checked damage policy"],
 "refund_amount": 640.00,          "blocked_by": "refund > $500 limit",
 "recommended_action": "Approve full refund of $640"}
